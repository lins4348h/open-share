# open-share

小林老師（引路人）的公開分享：特教、社交技巧與教學工具的做法，可以下載、改成自己的版本。

| 分享 | 內容 |
|---|---|
| [劇情聚光燈](spotlight-scenes/) | 用動畫劇本取代社交技巧課的真人示範：同一個場景先演錯讓學生找錯，再演對。附做法、劇本格式、可播放的示範頁。 |
| [數學出題助手](math-exam-generator/) | 國中數學出題工具：選單元、題數、難度、題型，用 Gemini 出一份考卷，可改題、排序、匯出 PDF。單一 HTML 檔，下載就能用。 |
| [《老師，在嗎？》](teacher-ping/) | 教師職場情境遊戲：下班後訊息一直來，選家長、主任或同事，6 回合、每則 20 秒，三種回法各有代價。附原始碼、劇本、測試，和每一版為什麼改的製作歷程。 |
| [拖移解題板](https://github.com/lins4348h/education-math-board) ↗ | 國中數學課堂遊戲起手包：學生把卡片拖進算式空格，一行一行組出解題過程，選錯會說出錯在哪。用 AI 打開就能新增自己的單元，附自動驗算。獨立的 repo，可以直接 Fork。[試玩](https://lins4348h.github.io/education-math-board/) |
| [旅誌 Trip Notes](https://github.com/lins4348h/trip-notes-template) ↗ | 手機優先、多人共編的旅遊行程網站範本：行程、照片回顧、預約、記帳分帳、當地語言救急句。旅伴不用註冊，拿到連結就能編輯。獨立的 repo，一鍵架到自己的 Cloudflare。 |
