# open-share

小林老師（引路人）的公開分享：特教、社交技巧與教學工具的做法，可以下載、改成自己的版本。

| 分享 | 內容 |
|---|---|
| [劇情聚光燈](spotlight-scenes/) | 用動畫劇本取代社交技巧課的真人示範：同一個場景先演錯讓學生找錯，再演對。附做法、劇本格式、可播放的示範頁。 |
| [數學出題助手](math-exam-generator/) | 國中數學出題工具：選單元、題數、難度、題型，用 Gemini 出一份考卷，可改題、排序、匯出 PDF。單一 HTML 檔，下載就能用。 |
