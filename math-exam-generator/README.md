# 數學出題助手

國中數學老師用的出題工具：選單元、題數、難度和題型，AI 幫你出一份考卷，可以直接改題、調順序，再存成 PDF。

👉 下載 [`index.html`](index.html)，用瀏覽器打開就能用，不用安裝。

## 可以做什麼

- 依 108 課綱的課程單元出題
- 題數：12／16／20／25 題
- 難度：基礎、中等、挑戰，或混合配比
- 題型：單選、填充、計算與應用，或混合
- 每題可以編輯題目和選項、刪除、拖曳調整順序
- 附標準答案與完整解題步驟
- 卷面可改學校名稱、考試名稱，匯出 PDF
- 數學式用 KaTeX 顯示

## 使用前要準備

這個工具用 Google Gemini 出題，需要你自己的 Gemini API 金鑰（到 Google AI Studio 申請）。有兩種用法：

1. **貼到 Gemini Canvas 裡用**：不用另外設定金鑰。
2. **自己開檔案用**：在網址後面加上 `?api_key=你的金鑰`。金鑰只存在你的瀏覽器，不會傳到別的地方。

金鑰是你個人的，不要分享含金鑰的網址。

## 提醒

- AI 出的題目和答案可能有錯，**發給學生前請老師自己驗算一遍**。
- 需要連網（載入字型、KaTeX 等）。
