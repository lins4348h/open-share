# 《老師，在嗎？》製作歷程

引路人・教師職場情境遊戲。下班後手機一直響，玩家選一個人（家長／主任／同事），固定走完 6 回合，每則回覆 20 秒。每回合三種回法：**顧對方、顧自己、守原則**，各有代價，沒有標準答案。玩完看結局，再看「八面玲瓏範本」。

- 上線方式：`dist/index.html` 拖到 Netlify（單一檔案，含瀏覽計數）
- 劇本文件：[《老師，在嗎？》劇本 v2](https://claude.ai/code/artifact/49d7b0de-3a39-4f9a-8ebb-3a8699c808fd)
- 開發期間預覽：[Claude Artifact](https://claude.ai/artifact/Pz4cLnHQLZs6VFku4vczJr)（私人）
- 製作期間：2026 年 10 月 4–5 日，和 Claude Code 一起完成

> 這個資料夾**不會**自動部署。網站的 `netlify/` 推到 main 會直接上線，所以遊戲放在 `games/` 底下，另外用 Netlify 拖曳上傳。

## 三、最終規格

**流程**：首頁（標題 →怎麼玩 →「今晚，你要回誰？」）→ 選人頁 → 背景卡 → 6 回合 → 結局卡 → 八面玲瓏範本（一回合一頁）。

**每回合**
- 3 個選項，各代表一個方向，順序隨機，遊戲中不標方向。
- 選完對方先針對你的回法反應，再進下一回合。
- 20 秒倒數，剩 10 秒對方追訊；超時＝已讀不回，算「顧自己」。
- 少數訊息會隨前面的選擇改變（資料裡的 `when`）。

**另一個人插進來**：只跳深色通知＋返回鍵紅點，**點開才看得到選項、才開始倒數**；沒點的話每 8 秒再震一次。

**來電（每個情境一通，算一回合）**：一定要接，沒有拒接鍵；響越久提示越明顯。接聽後語音＋字幕轟炸，中途插話一次（20 秒），對方講完掛斷。

**結局（看 6 回合的傾向）**

| 條件 | 結局類型 |
|---|---|
| 某方向比第二名多 2 以上 | 單一方向（3 種） |
| 前兩名差 1 以內（3–3–0、3–2–1） | 兩向混合（3 種） |
| 剛好 2–2–2 | 隱藏結局 |

結局卡是一段話，寫出這種傾向在**生活裡的後果**（例如一直顧對方 → 家人說「你對別人家的小孩比對自己家的人還有耐心」）。不做結局收集，可產生 1080×1920 結局圖卡。

**八面玲瓏範本**：每回合依序是對方訊息 → 對方心裡想 → 老師的真心話 → 八面玲瓏回法（旁邊並排「你剛剛的回法」）→ 為什麼這樣回（三個方向各一句）。開頭和最後各有一段深色提醒：「做不到很正常，我們都有情緒。」

**視覺**：「檯燈下的晚上」。首頁深焦糖底＋琥珀燈光＋書桌插畫；內頁奶茶米白＋紙張紋理；膠囊按鈕，每個畫面只有一個橘色主按鈕；手機上滿版。

## 四、內容寫作原則（從使用者回饋整理）

1. **體驗為主，不要像課程**。遊戲中不給提示，提示全部放到八面玲瓏範本。
2. **每個選項都要有代價**。不能有一眼就知道的完美答案，否則大家都選它。完美回法只出現在範本裡，而且是「三個方向的平衡」。
3. **三個方向的寫法**
   - 顧對方：答應、讓步、攬下來（代價是自己的時間和原則）
   - 顧自己：拖延、婉拒、躲（代價是關係和誤會）
   - 守原則：講規定、講公平、講事實（代價是聽起來很冷）
4. **一次只處理一件事、一個主要對象**；切換對象要讓玩家自己點。
5. **節奏要慢到讀得完**；寧可多 5 秒，也不要來不及讀。
6. **背景卡先寫背景，再寫現況**，最後一句是「突然，手機亮了……」。
7. **幼教到高中都通用**：用孩子、帶班、聯絡簿、學習紀錄、顧班、親子活動、辦公室群組；避免段考、記過、補習班、學年。
8. **寫實帶黑色幽默，沒有純反派**：每個「壞人」在內心戲裡都有自己的理由（宇振媽媽是怕孩子被欺負、王老師是怕在校長面前沒面子）。
9. **劇情要經得起每條路線**：寫完一定要沿著「全部配合」「全部拒絕」等極端路線讀一次，看後面的台詞還說不說得通（同事情境就是這樣抓到「當眾打臉」的破綻）。
10. **老師的真心話要先寫情緒**，例如「其實很想回：我有寫聯絡簿好嗎！」，再寫怎麼回比較好。

## 五、引擎重點（`src/app.js`）

**狀態**：全域 `G`，包含目前回合 `r`、選擇紀錄 `picks[]`、計分 `counts{o,s,p}`、目前視窗 `active`、未讀 `unread`、時間偏移 `offset`。每次開新局 `tok` 加一，所有非同步流程都用 `alive(tok)` 檢查，離開或重玩時舊流程會自動停。

**主流程**

```
startGame → 背景卡 → buildPhone → runRound(0)
runRound(i)：播放對方訊息（不在目前視窗就只跳通知）
  ├─ 有 call → runCall → 接聽 → 語音＋字幕 → 插話（callAnswer）→ callEnd → nextRound
  └─ beginChoice → 在同一視窗就 startChoiceTimer；否則等玩家點開
        pick(k) 或 onTimeout → 記錄方向 → 對方反應 → nextRound
nextRound → 第 6 回合後 finish → endKey(counts) → 結局訊息 → showEnd
```

**其他機制**
- `okWhen(item)`：資料裡的 `when:{r, d, to}` 決定這則訊息出不出現（第 r 回合選了 d，`to` 可區分是否超時）。訊息、來電台詞都適用。
- `ph(text)`：短句按標點切成一句一句，換行只發生在句與句之間（聊天、選項、字幕、標題）。
- `pp(text)`：長段落正常排滿，只把最後一小句黏住，避免最後一行只剩一兩個字。
- `avh(v)`：資料裡的 emoji 自動對應到 `avatars.js` 的插畫頭像（頁面用 `<use>` 引用同一份 SVG）。
- `pickVoice(g)`：語音挑選優先序是台灣口音 → 自然語音（Natural／Online）→ 依角色性別；沒有語音或語音失敗時自動改成字幕節奏。
- 瀏覽計數：`STATS_URL` 與無限流遊戲相同，`?tool=老師，在嗎？`；Claude 預覽頁不會計數，上線後才會。

## 六、劇本資料格式

```js
SCEN.parent = {
  id, role, name, av, title, teaser, preview, previewTime,
  bg: ['背景一句', '背景二句', '', '現況一句', '突然，手機亮了……'],   // '' 是段落分隔
  threads: { main:{ name, av, sub }, kai:{ ... } },                     // main 是開場的對話
  cardQuote: '結局圖卡上的那句話',
  rounds: [ /* 固定 6 個 */ ],
  endings: { o, s, p, os, op, sp, h }                                   // 每個 { n:名稱, t:收尾, items:[收尾訊息], hidden? }
};
```

**一般回合**

```js
{ t:'21:06', th:'main',
  items:['訊息', { text:'只在第2回合選顧對方時出現', when:{ r:1, d:'o' } }, { voice:{ d:'0:48', text:'…' } }],
  chase:'老師？',                          // 或 { typing:true }、群組用 { from, av, text }
  opts:[ { d:'o', t:'選項', re:['反應'] }, { d:'s', … }, { d:'p', … } ],
  timeout:['超時後對方說的話'],
  tpl:{ inner, feel, best, why:{ o, p, s }, who? } }   // who：群組回合寫內心戲屬於誰
```

**來電回合**：`call:{ from, av, voice:{ rate, pitch, g:'m' }, p1:[台詞], opts:[{ d, t, p2:[掛斷前的話], dur? }], to:[插話超時], miss:[保留備用] }`。`dur` 會讓通話紀錄跳成幾分鐘（家長情境「講了 41 分鐘」）。

**群組**：thread 加 `group:true`，訊息寫成 `{ from:'王老師', av:'👩‍🏫', text:'…' }`。

**訊息類型**：字串、`{typing}`、`{unsend:'會被收回的話'}`、`{voice}`、`{div:'時間分隔'}`、`{sys:'系統訊息'}`、`{wait:毫秒}`。

## 七、新增一個情境的步驟

1. 先在劇本文件寫好：背景卡（背景→現況）、6 回合（其中 1 回合來電、至少 1 回合由另一個人插進來）、每回合 3 個方向的選項與反應、超時反應、八面玲瓏範本、7 個結局。
2. 沿著極端路線讀一遍（全顧對方、全顧自己、全守原則、全超時），把說不通的台詞改成 `when` 條件句。
3. 複製一個 `data_xxx.js` 改內容，加進 `build.py` 和 `app.js` 的 `ORDER`。
4. 新角色要頭像就在 `avatars.js` 加一個 SVG，並在 `AV_EMOJI` 對應一個 emoji。
5. `python3 build.py` → `node tests/e2e.mjs`，看截圖和「沒有 JS 錯誤」。

## 八、踩過的坑

| 問題 | 原因 | 解法 |
|---|---|---|
| 群組發話者名字變成空白卡片 | 首頁卡片和聊天發話者都用 `.who` | 聊天改用 `.snd` |
| 手機上通知列蓋住返回鍵、按不到 | 通知列定位在整個螢幕頂端 | 改放在對話區頂端 |
| 對話列表點不到第一列 | 通知列 z-index 比列表高 | 列表提高到 17 |
| 測試時倒數總是先跑完 | 離線環境截圖會一直等 Google Fonts | 測試一律擋掉字型請求 |
| 小手機背景卡超出畫面、按不到開始 | 舞台 `overflow:hidden` | 背景卡可捲動、手機字級縮小 |
| 結局圖卡頭像畫不出來 | SVG 裡同一屬性寫了兩次，獨立成圖片時解析失敗 | 改用 `st(寬度)` 產生屬性 |
| 長段落一句一行像新詩 | 長文也套用逐句換行 | 短句用 `ph`、長段落用 `pp` |
| 語音在無頭瀏覽器 0 秒就結束 | speechSynthesis 立即報錯 | 沒有 onstart 或念太快就改用字幕節奏 |

## 九、之後可以做

- **真人配音**：每個角色 5–10 句，用手機錄，換掉電腦語音，帶入感會大很多；或用 Azure 語音的台灣自然語音預先產生音檔。

- **學生版**：同一套引擎，對象換成同學、老師、打工店長（另做一個遊戲）。
- **霸凌模擬器**：發想階段留下的點子。
